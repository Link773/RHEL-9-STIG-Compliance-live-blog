# RHEL-9-STIG-Compliance-live-blog
This is a repository that, despite mostly not working in code, has a README file containing everything I am doing for this project, including any blunders and problems I had to face due to this being my first time creating and hosting a virtual machine. Eventually my goal is to create code using Python and Ansible, as seems to be the standard, to automate the various processes of STIG compliance on this system using the Red Hat Enterprise Linux 9 STIG documentation version 2 Release 10 dated September 30th 2026. However, the initial goal is simply to read, understand, and know how to configure these standards by hand and the benefits and drawbacks of each configuration.
# Foreword
This project was started due to suggestions from a peer about things to learn about and do within cybersecurity, particularly with goals in mind to learn about security compliances and also display my capability of computers beyond my certifications.
I am also writing this in a sort of journal styling, so this will be mostly-chronological with dates above to say what I've done in each day.
# 11/21/2026
# Virtual Machine setup
Notably, this is my first time creating and hosting my own virtual machine. I have used virtual machines before in the form of a class on Red Hat Enterprise Linux and I guess technically various Java applications.
Most of my installation went off without a hitch. I've installed operating systems before on my desktop when I built and rebuilt it, as well as attempted dual booting and repeatedly installed operating systems on a raspberry pi before. My big problem however, I was struggling to get networking to interface how I desired. I determined that after creating my virtual machine, I needed to set a different network adapter configuration for the particular virtual machine after creating it while it was off to allow it to connect to the internet how I wanted.
# Initial setup within machine

The only problems I had in this stage moreso had to do with preference.
