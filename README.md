# RHEL-9-STIG-Compliance-live-blog
This is a repository that, despite mostly not working in code, has a README file containing everything I am doing for this project, including any blunders and problems I had to face due to this being my first time creating and hosting a virtual machine. Eventually my goal is to create an ansible playbook, to automate the various processes of STIG compliance on this system using the Red Hat Enterprise Linux 9 STIG documentation version 2 Release 10 dated September 30th 2026.
# Foreword
This project was started due to suggestions from a peer about things to learn about and do within cybersecurity, particularly with goals in mind to learn about security compliances and to document my own, informal or formal, findings about these guidelines as I'm attempting to lockdown a virtual machine within these guidelines. For more formal findings, look to the "Notable Rules" file. For more informal findings look to the "Journal" file.
